¿Por qué este proyecto?

Decidimos desarrollar este proyecto porque en la actualidad se están optando por las fuentes de energía renovables pero estas aún no se están aprovechando del todo. Por eso trabajamos en hacer este proyecto: para sacar el máximo provecho de nuestros paneles solares y así poder tener un mejor rendimiento de estos.
